# Contributing to Awesome Databases

Thank you for helping curate this collection! Please follow these guidelines before opening a Pull Request.

## Guidelines for Submissions

1. **One Category Rule:** Place the database strictly under its primary core architecture. Do not add a database to multiple sections.
2. **Standard Format:**
   `- [Database Name](https://homepage-or-github) - Short description ending with a period. \`Primary-Language\``
3. **Alphabetical Order:** Keep entries sorted alphabetically within each section.
4. **Active/Relevant:** Ensure the project is maintained, documented, or historically significant.

## Submission Checklist
- [ ] Added to the correct single-purpose category.
- [ ] Entry is placed in alphabetical order.
- [ ] Description is neutral, concise, and ends with a period.
- [ ] Link works and uses HTTPS.
