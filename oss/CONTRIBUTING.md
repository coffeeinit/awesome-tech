# Contributing

This list is maintained casually, not exhaustively — corrections and additions are welcome.

## Adding a tool

- Open a PR adding your entry to the relevant category table (or propose a new category if none fits).
- Keep the row format consistent with the rest of the table: name, link, one-line description, license, and any other columns already used in that section.
- Prefer tools that are actively maintained and genuinely open-source (not "open-core with a crippled free tier" unless clearly labeled as such).
- Double check the link resolves and the license is stated correctly — don't guess.

## Fixing an entry

- Stale link, wrong license, project archived/renamed/dead — open a PR or an issue, whichever is easier for you.

## Scope

This directory favors breadth across the general engineering surface (infra, backend/frontend, data, security, mobile, dev tooling, per-language libraries). Deep AI/ML delivery tooling (agents, RAG, evals, model serving) belongs in a dedicated AI/ML list rather than here — keep additions roughly within the existing category shape.

No specific PR template — just be clear about what changed and why.
