# Contributing

Thank you for helping keep Awesome Crypto useful and credible.

## Entry requirements

1. Prefer primary sources: official project sites, official documentation, official source-code organizations, standards bodies, central banks, and established public institutions.
2. Use a neutral description. Do not make price, profit, or safety promises.
3. Include the official site, source repository where available, documentation, and a whitepaper/specification or an explanation of why none exists.
4. Do not add contract addresses to the main catalog. Link to official network-specific documentation instead.
5. Check that links work and that the project is not an obvious impersonator, phishing site, or unsupported promotional token.
6. If a project is inactive, compromised, renamed, or superseded, open a pull request to label or remove it.

## Pull requests

Update both `README.md` and `data/catalog.csv` when changing the catalog. Keep changes focused and explain the primary sources you checked.
